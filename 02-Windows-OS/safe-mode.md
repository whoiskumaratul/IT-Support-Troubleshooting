
# What is Safe Mode?

Safe Mode is a Windows troubleshooting mode that starts Windows with only the essential drivers and services.

# Why do we use Safe Mode?

It helps determine whether a problem is caused by:

- Third-party drivers
- Startup applications
- Recently installed software
- Security/utility software
- Driver conflicts

# How to enter Safe Mode — Windows 11

Method 1: From Windows

-Settings → System → Recovery
- Under Advanced startup → Restart now
- Troubleshoot → Advanced options → Startup Settings
- Click Restart

- Press 4 → Safe Mode
- 5 → Safe Mode with Networking

# IT Support troubleshooting approach

Normal Windows issue → Boot into Safe Mode → Check whether issue still occurs

Issue disappears in Safe Mode → likely third-party driver/software/startup-related.
Issue still occurs in Safe Mode → investigate Windows components, hardware, or other deeper causes.

Important: Safe Mode is a diagnostic/troubleshooting mode, not a permanent solution.
