

Ticket - USB device not detected and not recognized 

First we will try to connect and check each and every peripherals devices like keyboard, mouse, headphones etc and after plugin if any popup will be coming in right bottom side
like USB not detected and not recognized so then we will update or reinstall manually drivers in device manager 

# For open device manager

- Win + r and type diskmgmt.msc and hit enter 
- after opening the device manager go to Universal Serial Bus Controller and inside the Universal Serial Bus Controller right click on USB composite device, USB 3.0 eXtensible
  Host Controller and uninstall the driver then
- single click on Action Navbar and hit Scan for hardware changes like that
- Again you can see they came again USB 3.0 eXtensible host controller, USB composite device
- Now restart the system and try to see resolved USB device not detected and not recognized.
