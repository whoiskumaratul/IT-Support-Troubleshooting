SAC Code stands for Services Accounting Code.

It is a GST classification code used in India to identify the type of service being procured or provided, similar to how HSN codes are used for goods.

In the email you have open, the SAC code mentioned is 998715.

Generally:

SAC → Used for services
HSN → Used for physical goods/materials
Goods Receipt Note (GRN)
Procurement and Finance teams use SAC codes for GST calculation, accounting, and PR/PO processing.
